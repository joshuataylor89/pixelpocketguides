How to Run Gen1Recomp on a Retro Handheld

Updated November 10, 2026

Gen1Recomp is a native recreation of Pokémon Red, Blue and Yellow. It is not an emulator, so there are no cores or BIOS files to set up. Whether it runs on your handheld depends mostly on the device.

Quick overview

  • You need your own game file. The app asks you to import a copy of the US Red, Blue or Yellow game that you made from a cartridge you own. It does not include the game.
  • Anbernic RG34XX SP: per Held Games, the only dedicated retro handheld with an official build, and only on the stock OS using PortMaster.
  • Android handhelds: install the app and play with touch or a controller.
  • Steam Deck and Windows handhelds: the best choice if you want the optional 3D, first-person or VR mods.
  • Not supported: custom firmware like muOS, KNULLI, ArkOS and ROCKNIX, and most other cheap Linux handhelds.
