Getting Started with Gen1Recomp on a Handheld

Updated November 10, 2026

Gen1Recomp is an unofficial fan project that recreates classic Pokémon games to run natively, rather than as a standard Game Boy emulator. It is not affiliated with Nintendo, Game Freak or The Pokémon Company.

Quick overview

  • You need your own game file. The project does not include or link to game files. You import a compatible US copy that you made from a cartridge you own, and the app only accepts specific versions.
  • Platforms: the project's FAQ lists guides and builds for Windows, Mac, Android and Linux, plus homebrew builds for Nintendo Switch and PlayStation 4.
  • Anbernic RG34XX SP: reportedly the only dedicated retro handheld with an official build, and only on the stock OS using PortMaster.
  • Android handhelds: install the app and play with touch or a controller.
  • Steam Deck and Windows handhelds: the best choice if you want the optional 3D, first-person or VR mods.
  • Custom firmware: reportedly not supported on muOS, KNULLI, ArkOS and ROCKNIX, or on most other cheap Linux handhelds.
  • Check before you install. The device notes above come from community reports and the project's own FAQ does not list them, so confirm your exact device before you buy or install anything.
  • Availability is not a guarantee. The project notes that a download existing does not mean every OS version, GPU, controller or firmware is supported.

Read the official details

Install steps, supported games and platform guides change as the project updates, so go to the source before you install.
